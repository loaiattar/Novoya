# NNNN. Title in a few words, as a decision

- **Status:** Proposed | Accepted | Replaced by [NNNN](NNNN-file.md)
- **Date:** YYYY-MM-DD
- **Issue / PR:** #n

## Context

What forces the choice: the need, the constraints (school rules, deadline, GDPR), what we
know today. Facts only, a few sentences.

## Decision

What we do, stated plainly: "We use X for Y." Add the few rules that follow from it.

## Options considered

Only the options the team really weighed, one line each, with why they lost. Leave the
section out if there was no real alternative.

## Consequences

What gets easier, what gets harder, what we must now do or watch. Name the files, settings
or tests that carry the decision.
